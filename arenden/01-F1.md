# F1 – CI har varit rött sedan förra veckan
Etikett: felsök

Workflowet CI har varit rött sedan förra veckan och ingen har hunnit titta på det. Ta reda på
varför och rätta det.

**Tips:** läs loggen nerifrån och upp. Det verkliga felet står oftast strax ovanför
`Process completed with exit code`. Kör samma kommando lokalt i en ny, tom miljö och jämför.

**Klart när:**
- [x] Du kan förklara i en kommentar här vad felet var och varför det inte märktes lokalt.
Svar: Felet beror på att pip install endast installerar dependencies och inte optianl dependencies. Löst genom att lägga till .[dev] i `run: pip install -e` i `ci.yml`. Att det fungerar på datorn är för att vi manuellt har installerat alla dependencies när vi startade projektet. 
- [x] Steget som felade är grönt. (Det kan finnas fler fel efter det, se F2.)
